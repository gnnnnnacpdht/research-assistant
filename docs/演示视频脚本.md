# 《AI 科研助手》演示视频录制脚本

> 风格：纯录屏、不出镜、一镜到底；每句口播配屏幕底部一行白色大字字幕
> 时长：约 6 分钟（可按段落裁到 4 分钟）
> 公网入口：`http://{{在这里填新的 cpolar 地址}}`
> 本地兜底：`http://127.0.0.1:8000`
> 库里论文：24 `1706.03762v7.pdf`（15 页）、25 `1706.03762v1.pdf`（15 页）、
> 27 `UnderstandingDeepLearning_02_09_26_C.pdf`（541 页）、31 `2005.14165v4.pdf`（75 页）

## 一、风格规则

1. **不出镜**，全程只有屏幕，任务栏、IDE、终端不入镜。
2. **一镜到底**，不切镜头不加转场，靠点击卡片、切换侧边栏换场景。
3. **一句一字幕**，字幕在底部居中偏下，白色粗体，每行 10–20 字。
4. **说一句做一个动作**，字幕出现时鼠标正在点那个东西。
5. **像给同学讲**，用"你看""其实""就是说"这种口语，别念稿子。

表格里「口播」是照着念的话，允许临场改词；「字幕」是剪映里要上的短句。

## 三、后期怎么做

1. **录屏**：OBS 选「窗口捕获 → Chrome」，1920×1080、30fps，一镜到底中间不停。
2. **字幕**：剪映导入 → 文本 → 智能字幕 → 识别 → 按上表逐句校准。
   样式：白色、粗体，字号约屏高 5%，位置在底部往上约 8%，居中。
3. **对齐**：字幕和鼠标点击同时出现，宁可晚 0.3 秒也别提前。
4. **音频**：不加 BGM 也够；要加就压到 -25dB 以下，别盖住人声。
5. **导出**：1080p、30fps、H.264，码率 8–10 Mbps，控制在 500 MB 内。

## 五、最容易翻车的 3 个点

**1. 公网地址打不开**
cpolar 免费隧道会换域名。录制前 5 分钟自测；挂了就用 `localhost:8000` 录，开场字幕改成"这是我本地跑的服务，公网地址在 README 里"。绝不现场折腾隧道。

**2. 去重弹窗内容与预期不一致**
v1 已在库里，可能显示"与 25 号 100% 相似"。事先演练看清实际显示，按实际改字幕，或提前删掉 25 号。

**3. 问答现场变慢或答案不同**
DeepSeek 偶发 20 秒以上。提前问一次确认；现场卡住就把字幕改成"这里在做引用自检"；超 40 秒切 `screenshots/验收/06_问答页.png` 讲截图。

### 两个小坑

- 541 页阅读页不重建结构，会露出"目录（0）"和"论文 #27"。
- Agent 轨迹默认展开，记得配一句字幕解释它是什么。
